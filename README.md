# Welcome to rusty-wifi-map!
Rusty wifi map is a JSON-based database intended to allow users to know when and where wifi is available. Programmed in Rust, this simple CLI tool tells you where wifi is availible.

## Rules
While this may be a interesting project, there are some rules to come along with it.
- **No additions of private or home networks** This is an invasion of privacy and is against GitHub's terms of service.
- **No inputting of private information** This includes but is not limited to names, addresses, emails, phone numbers, passwords etc.
- **No unauthorized data**If you have to break the law or violate an organization's terms of service or end user agreement to get it, don't put it on.
